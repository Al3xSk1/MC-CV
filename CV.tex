\section{Profile}

Minecraft plugin and server systems developer with professional and independent
experience building custom gameplay, infrastructure, and content-facing systems
for heavily modified Minecraft environments. Primary development is in Java,
with additional experimentation in Kotlin and Skript where it fits the project.
Comfortable working across Paper, Folia, MultiPaper, ShreddedPaper, Spigot, and
Velocity, including projects that substantially alter Minecraft's mechanics,
server behavior, and presentation layer.

I work best on servers that need more than small utility plugins: custom
mechanics, integrations between complex plugin ecosystems, database-backed
features, server-specific workflows, and code that has to survive real player
traffic.

\section{Development Approach}

I enjoy working close to the server implementation and building systems that
push Minecraft beyond its standard gameplay model. I am particularly interested
in performance-sensitive server development, custom gameplay mechanics,
large-scale rewrites, and integrating multiple systems into cohesive server
experiences.

My approach is practical: understand the existing server first, build features
that fit its architecture, and keep code maintainable enough that future
releases are not painful. I care about how systems feel to players, how they
behave under real server conditions, and how easily other developers or server
owners can reason about them later.
